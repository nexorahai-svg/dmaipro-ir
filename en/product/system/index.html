Install, running, security and phone

Install and licence

One smart installer

The installer puts everything in place at once: the app, the AI engines and models, voice-message reading and the tools. It needs no Windows administrator rights and installs for the current Windows user.

  • Windows 10 (version 1809 or later) or Windows 11, 64-bit
  • No administrator rights needed
  • Suggested folder C:\DMAiPro; it warns about the Desktop, Downloads, OneDrive and paths with spaces
  • Options: start with Windows, desktop shortcut, Start menu shortcuts, open the app at the end
  • Steps: welcome and checks, licence agreement, folder and options, copying, finish

Full install with no internet

The full edition carries every file and downloads nothing, so it installs even on a computer with no or slow internet. Its files come in parts under 4 GB so they fit on any USB stick.

  • The setup program and its numbered parts must sit in one folder
  • Each part is under 4 GB, the file-size limit of many USB sticks
  • A missing or damaged part is named in a clear message

Light install: only the models you need

The light edition measures the computer first, shows the list and size of the models it needs before downloading, then fetches only those from each model's official source. The download page works like a download manager: speed, time left, pause and resume.

  • Two files at a time, up to 6 tries per file
  • A broken download goes on where it stopped, even after setup is closed and opened again
  • Each file is checked against its fingerprint before use
  • Free disk space is checked before downloading

Computer check during install

After install, the «Your computer» page says what level this computer is and what it lacks, in Persian, Arabic or English to match Windows' language.

  • Checks: 32-bit Windows, Windows older than 10 (1809), a missing Windows part the app window needs, memory under 4 GB, a processor too old for the AI, a graphics card with no driver or in error, a driver 2+ years old, a graphics card without the needed support, too little disk space

Graphics driver advice

If the graphics driver is missing, old or in error, the installer says so and opens the maker's official page in the browser with one button; it downloads nothing itself.

  • Official pages: NVIDIA, AMD, Intel and Microsoft

Installs only original files

Every file is compared with its fingerprint and the publisher's signature is checked before anything is replaced. A changed or forged setup is refused and the earlier install stays as it was.

  • An older version over a newer one is refused unless chosen on purpose
  • A cancelled install leaves no half-written file

Update without losing data

Running the installer over an existing install switches to «Update» mode: it closes the app, replaces the program files and keeps messages, settings and the licence.

  • An update never touches the data folder

Safe uninstall

The app is removed from Windows' «Installed apps» and the data is kept by default. Deleting the data needs the word DELETE typed, and the newest encrypted backup is first copied to the Documents folder.

  • The backup is copied to a «DMAI Pro backups» folder in Documents
  • Pressing Enter alone never deletes the data

7-day full free trial

Every feature works free for 7 days. Reinstalling does not start a new trial, and turning the clock back adds no days.

  • Top bar badge: «Demo · days left»

Licence key for this computer, offline

You send this computer's code to the seller, then paste the licence key in the panel or pick the .lic file. Activation works offline; a key can be permanent or until a date, and renewal is a new key.

  • Computer code: 20 letters and digits, with no look-alike characters
  • A key made for another computer is refused with a clear message

Nothing lost after the trial

If the trial ends with no key, the app goes read-only: customers' messages are still received and kept, but nothing is sent until a key is entered.

Silent install for resellers

For rolling out to several computers, install and uninstall can run with no window through command-line options.

  • A silent install can set the folder and skip start with Windows, the desktop shortcut, Start menu shortcuts or opening the app at the end
  • A silent uninstall can also delete the data when asked to

Setup fits the screen

The setup windows grow with the screen's real size, so they are not tiny on a tablet or a small screen.

Licence state always visible

A badge in the panel's top bar shows the trial days left, the licence end date or that it is permanent, and opens the activation page.

Always on and up to date

Starts with Windows

When you sign in to Windows, the app starts quietly and sits next to the clock, so messages are answered whenever the computer is on. Switch it on or off on the System page.

  • No administrator rights; a shortcut goes in the user's own Startup folder

Watchdog restarts it

The app is checked every 30 seconds; after three missed checks in a row (about 1.5 minutes) it is started again. If you stop it on purpose, the watchdog stops too.

  • No endless restarts while the app waits for a busy port to free up

Unfinished work resumes

Messages and jobs are kept in a queue; if the app or the computer stops mid-task, that job is picked up again after the restart.

A message that crashes the app is set aside

If the app stops three times in the middle of one job, that job is set aside so the app does not keep stopping, and the team is told to open that conversation themselves. Closing the app on purpose or an update does not count.

  • Every other interrupted job goes back to the queue

Its own desktop window

The panel opens in the app's own window, with no address bar or tabs. Its size and place are remembered, and closing it only hides it: replies go on and the icon next to the clock opens it again.

  • Menu on the icon next to the clock: open, open in the browser, stop
  • One copy only: starting it again brings the window forward
  • If the Windows part the window needs is missing, the panel opens in an Edge window or the browser

Updates from inside the app

The app looks for a new version at start and every 6 hours. When there is one, an «Update available» badge shows what's new and the download size; one click downloads, checks and installs it, keeping messages, settings and the licence.

  • What's new in Persian, Arabic and English
  • Size and fingerprint must match before anything is unpacked
  • Nothing is installed without the owner's click
  • Downloads come only from the publisher's own download site

Busy-port warning

If another program holds the port the app uses to receive messages, the app does not crash: it waits and tries again, and the panel shows a red bar naming the program and the port.

  • It also explains a port Windows has reserved or one that needs administrator rights

Connections re-tested daily

Every connection you set up, such as channels, AI keys and payment gateways, is tested again automatically once a day, so anything that stopped working shows in the panel.

  • A «Test all» button checks everything right now

Built-in AI engine and app parts

Model downloads that resume

Any model not here is downloaded from its fixed official link; a broken download resumes where it stopped, and the file is checked against its fingerprint before use. A file that does not match is never used.

  • Reply models: Qwen3.5 0.8B, 2B, 4B, 9B and Gemma 4 E2B
  • Helper models: picture reading, search by meaning, and voice-note reading (Whisper small, medium, large-v3-turbo)
  • A «Check the file» button on each model

Finds and fills missing parts

The app lists what this computer lacks and the «Download everything missing» button fetches them one by one, smallest first. If an antivirus removed part of the app itself, it tells you to run the installer again; your data stays.

  • Covers: the AI engine, the voice-note engine, the models, and the voice-reply engine when voice replies are on

Full system check in the panel

The System page shows the operating system, processor, memory, graphics card and disk with a status for each, the required software with its official pages, and checks reach to the internet, Instagram and Claude.

  • «Run check again» and «Quick speed test» buttons
  • Warns about a regular hard disk (HDD) for models and about low free space

Engine files checked before each run

The engine's files are compared with the checked copy before each run and unpacked again from the intact package if changed. Only the app itself, on this computer, can use the engine, with a private key that changes every run.

Public address and phone app

Fixed address in one click

With the «Get a fixed address» button, the app gets a fixed address from the publisher's service, sets it up and tests it itself: no Cloudflare account, no domain, nothing to paste. With a licence the address is lasting and named after the business.

  • During the trial: a trial address, removed after the trial ends

Phone app for the day's work

The owner and the team do the day's work from anywhere on the phone: chats by channel, approving or editing AI drafts, confirming a payment after seeing the receipt, tasks and tickets. Everything happens on the computer at once and nothing stays on the phone.

  • Tabs: Today, Chats, Work, More
  • Today: waiting customers, drafts, payments to review, tasks, hot leads
  • In a chat: reply, take over, photos, voice and files, internal notes, the customer sheet (stage, tags, notes, assign)
  • Added from the browser to the home screen; no app store
  • Android and iPhone; Persian, Arabic and English
  • Search the chats, mark all alerts read, choose the app's language on the phone
  • Checks for new messages every 8 seconds while open
  • refreshes every 30 seconds while open

Fixed address on your own domain

With your own Cloudflare account and domain you make a fixed address for messages and customer links; the app runs it with its bundled tool, with a step-by-step guide in the panel. If the route does not reach the app, the reason is shown.

Temporary address for trying

For trying, a temporary address is made with no account or sign-up. The panel says plainly that it changes at every start and that a fixed address is needed before connecting Instagram or WhatsApp.

Public address kept alive

Every 2 minutes the app checks that the public address opens from the internet; after two misses in a row a new tunnel starts and the address is registered with the channels again. A «Create new address» button does it by hand.

  • Your own fixed https address is never replaced

Pair a phone with a QR code

The owner makes a QR code in the panel that works once, for 5 minutes; the phone scans it and gets its own key. Each phone is paired for a chosen account.

  • Needs the fixed public address
  • iPhone: a one-time move code carries the pairing from Safari to the home-screen app (15 minutes)

Manage connected phones

The panel lists the phones with name, pairing time and last use, and disconnects any of them at once with a tap. A phone unused for 60 days is disconnected automatically.

  • A password reset, «sign out everywhere» or a disabled account also cuts that account's phones

Phone limited to daily work

From a phone, settings, channels, keys, backups, security and users cannot be touched; this is enforced on the computer itself, not just by hiding buttons.

  • A phone gets at most a staff account's rights; a view-only account stays view-only

Phone alerts with quiet hours

Every team alert also reaches the phone, and tapping it opens that conversation. Each phone chooses which kinds of alert it gets and its quiet hours.

  • Kinds: customer waiting, AI draft, payment, task, other
  • Quiet hours follow the business time zone
  • Works without any paid notification service
  • needs a fixed public address for the panel

Alerts without sensitive data

Card numbers, IBANs, phone numbers and e-mails never go into an alert, and the alert is encrypted so that the delivering service cannot read it.

Every public-address option

Besides the temporary address and a Cloudflare tunnel, you can give your own https address, use a fixed ngrok domain (with ngrok installed yourself), or switch the public address off.

  • Modes: temporary, Cloudflare tunnel, ngrok, your own address, off

Only the verified Cloudflare tool runs

On Windows only a fixed, checked version of the Cloudflare tool runs; if it is missing, the app fetches that official version and checks its signature and fingerprint.

Last lists shown when offline

If the computer cannot be reached, the phone shows the last lists read-only and keeps no whole conversation. When a phone is disconnected, everything on it is wiped.

Panel login and data security

Customer texts stored encrypted

Everything customers write is kept encrypted in the database; a copy of the data file or of the whole disk shows none of it. Freed space is zeroed so no readable copy is left behind.

  • Covers: messages, comments, voice-note texts, form answers, notes, ticket texts, drafts, task notes, the AI's working notes, messages as they arrived, and waiting jobs

Admin panel only on this computer

The admin panel cannot be reached from the internet and opens only on this computer; a web page that disguises itself as the panel's address gets no answer.

Password login for the panel

Once the owner account is made, opening the panel needs a password. It is at least 10 characters and stored in a form that cannot be read back even from the database.

  • Before an account exists, the panel opens only in the app's own window on this computer
  • Changes are accepted only from the panel itself; another web page cannot act with your sign-in

Lock after wrong tries

After 5 wrong passwords the account locks for 15 minutes. Sign-in from the app's own window has a lane of its own, so a nuisance program cannot keep the owner locked out.

  • Also: 20 failures for one username from one device in 10 minutes lock that username on that device

Signed-in devices and sign-out everywhere

The Security page shows everywhere your account is signed in; sign one out or all the others at once. Changing the password signs the other devices out automatically.

  • A sign-in ends after 12 hours idle and after 7 days at most

Two-step login

Besides the password, a 6-digit code from an authenticator app on the phone is asked; even a leaked password then lets no one in. Each code works once and turning it off needs the password.

  • Works with any authenticator app (Google Authenticator, Microsoft Authenticator…)
  • Set up by typing the setup key or copying the link

Reset a forgotten password

A forgotten password is reset only on this computer and only with the recovery code; there the lock can also be lifted or two-step login switched off. Every try is logged.

  • Done with the password-reset tool in the app's folder
  • 3 wrong codes end the run; 6 within 30 minutes lock the tool for 30 minutes

Key vault

Instagram, Telegram and WhatsApp connection keys, AI keys and payment-gateway keys are stored encrypted. The master key lives outside the database, locked to your Windows user by Windows' own protection; a copy of the data folder alone cannot open it.

  • AES-256 encryption with a separate key for each use
  • If Windows' protection fails, the panel warns that the key is only protected by file permissions and tries again at the next start

Advanced payments

Guard when the master key goes missing

If the master key file goes missing, the app never makes a new key silently: a red bar in the panel, an alert on the team's Telegram when possible, and backups pause. The key comes back with the recovery code, or a new one is made knowingly by typing NEW.

  • 5 wrong recovery codes mean a 15-minute wait

Recovery code for a bad day

A code of 8 groups of 4 characters is made: the only way to open the backups on another computer. It is shown until you type it once to confirm; it can be printed or copied, and a new code can be made any time.

  • After confirmation it is never shown again
  • A new code opens future backups; older backups still need the old one

Detects changed program files

The program files are compared with the publisher's signed list at start and every 30 minutes. If something was changed or added, sending stops and a red bar stays in the panel until the original files are back; data is kept.

  • Only signed parts of the app and the panel are loaded
  • Panel pages are checked before they reach the browser

Only signed channel messages accepted

Instagram, WhatsApp and Telegram messages are accepted only with a valid signature, so a forged message never gets in.

Access log: who did what

Every view of a personal photo or file, every backup, deletion, sign-in, key change and settings change is recorded with the account that did it, and shown on the Settings page.

  • About 95 kinds of action, each with a plain label
  • Also: phone paired or disconnected, licence activated, customer data erased, Meta deletion requests

Security at a glance

The Security page shows how many of the main steps are done and whether each protection is on: keys, recovery code, encrypted backups, password login and the rest.

Sensitive steps only in the app's window

Until the owner account exists, showing the recovery code, list exports, the backup key and creating the first account work only in the app's own window; no other program on the computer can reach them.

  • A browser opened by the app gets a one-time code valid for one minute, never the secret itself
  • A new secret at every start

Signed requests to Instagram

Every request to Instagram is signed with the app's secret, so a stolen connection key alone is useless. If Meta refuses it, the app keeps working and says so on the Security page.

  • On by default; it can be switched on again from the Security page

Safe public pages

Forms, payment pages and the customer portal send the browser safety rules, and secret links never leak to other sites. A file a customer sends opens in the page only if it is a plain picture or sound; anything else is just downloaded.

Backups and recovery

Daily encrypted backup

Every day a full copy of the database and new files is made and encrypted while the app keeps running. The last 14 automatic copies and every manual one are kept, and without the recovery code nobody can read the backup folder.

  • Photos and files are copied incrementally (only new or changed files)
  • After a key change, the last backup made with the earlier key is never rotated out
  • A short instructions file in the backup folder says what is inside and how to restore
  • No readable copy of the database is left in the system's temporary folder

Back up now

Any time, the «Back up now» button makes a manual encrypted copy that the daily rotation never removes.

Restore on another computer

If the computer breaks or Windows is reinstalled, the backup folder plus the recovery code bring everything back on a new computer: database, files and the documents key. An existing database is set aside, not deleted.

  • Done with the restore tool in the app's folder (the app must be stopped)
  • The recovery code is typed on the keyboard and shown as *

Backup to another disk or synced folder

The backup folder can be moved to another disk or a synced folder with one line in the app's settings file; being encrypted, nobody can read it there either.

Restore check

For each backup you can check whether its encrypted documents will open after a restore or their key is missing; if the current key is lost, it is put back from the backup.

Documents key inside the backup

The key that encrypts customers' documents goes with the backup by default, itself encrypted. If you prefer to keep it yourself, it can be left out after a clear warning.

Document collection

Remove old unencrypted backups

Copies made before encryption are counted and shown, and after the first encrypted backup they can be deleted with one button.

Privacy and Meta rules

Logs without personal data

Log files never hold a connection key, password, e-mail, card number or phone number, masked even when written in Persian or Arabic digits. Customers' message texts are not written to the logs at all.

Old technical data removed automatically

Every day raw incoming data and finished jobs older than 90 days are removed, and old log files go after 14 days.

  • Conversations and customer records are not removed by this

Erase a person's data on request

If a customer writes «delete my data» in the chat and confirms, all of their data is erased at once: messages, forms, files, payments and even their name in old log files.

  • Backups made before the request keep it until they rotate out
  • The access log keeps only an anonymous line
  • Removes messages, comments, forms, photos and files, payments, notes, tickets, tasks, alerts, AI records, flow answers, translations, answers learned from their chats and their lines in old logs
  • Modules' records of the person are removed too
  • Their other apps keep their own files
  • Backups made before the request keep the data until they rotate out

Instant cut when access is removed

If the Instagram account removes the app's access, Meta notifies the app and the connection is dropped at once.

  • Only requests signed with the app's secret are accepted

Meta data-deletion requests answered

A data-deletion request from Meta is verified, then the connection and everything received about that account are deleted; a confirmation code and a public status page are returned as Meta requires.

  • The Security page shows both addresses to paste in the Meta app dashboard, and the last requests
  • Warns when the address is still temporary
  • Only requests signed by Meta are accepted
  • Your customers' conversations are your business records and are not part of this request

Data-deletion instructions page

A public page explains the three ways to have data deleted: writing in the chat, removing the app in Instagram, and asking the business; in the visitor's language with an English copy for Meta reviewers.

Panel comfort

Night mode

One button in the top bar switches the panel between day and night. With login on, each person's choice applies to their own account only.

Text and panel size

The panel size can be chosen, and «Automatic» measures the screen's real size to show it larger on a tablet or small screen. Each account's choice is saved separately.

  • Sizes: Automatic, 90%, 100%, 110%, 125%, 150%

Simple or full menu

The simple menu shows only the daily work in one short list; one button shows every section.

  • Simple view is the default; the choice is remembered in the browser
  • simple view is the default
  • setup stays first in the menu until its required steps are done
  • one entry per specialised section you switched on
  • related pages open as tabs at the top of the page
  • menu groups you collapse stay collapsed
